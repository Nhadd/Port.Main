RevWord — reverse word guessing game

This Android project challenges players to recognize a word displayed backwards. A countdown, score, and limited attempts create a short, focused gameplay loop.

What’s inside

  • A start screen and interactive answer entry.
  • Countdown timer, scoring, and limited attempts.
  • Pause, retry, settings, and game-over screens.

What I learned

Connecting Java game logic to XML layouts, managing changing game states, and balancing feedback with a time limit.
